# Speak Without Fear

Әбдиева Гүлмира мұғаліміне арналған ағылшынша сөйлеу платформасы. Next.js + TypeScript + Tailwind CSS. Қазақша, орысша және ағылшынша интерфейс; әр бөлімнің жеке беті бар.

## Іске қосу

```bash
npm install
npm run dev
```

`http://localhost:3000` → `/kk`. Тілдер: `/kk`, `/ru`, `/en`.
Бөлімдер: `games`, `challenge`, `speaking-room`, `test`, `progress`, `profile`, `fear-wall`, `mirror`, `cycle`.

Dev сервер `.next-dev`, ал өндірістік build және start `.next` бумасын қолданады. Осылайша build dev сервердің жинақ файлдарын өшірмейді. `npm run dev` бір жобаға бір ғана dev серверін ашады: екінші іске қосу бар сервердің адресін көрсетеді. Сервер толық тоқтаған соң жаңа іске қосу тек `.next-dev` жинақ кэшін жаңартады. Қайта іске қосарда бұрынғысын `Ctrl+C` арқылы тоқтатыңыз; `npx next dev` орнына `npm run dev` қолданыңыз.

## Мүмкіндіктер

- Фотоның орнына шағын интерактивті ойын және анимацияланған иллюстрация.
- Үш ойын түрі: сөз таңдау, сөйлем құрастыру, диалог. 24 тапсырма, аралас раундтар және күндік ұсыныс.
- Жеті қадамдық интерактивті бағдарлама; әр қадамда үш тапсырма. Аяқталмаған қадам жалғасады.
- Төрт тақырыптағы 16 сөйлеу сұрағы, дыбыстап оқу, браузердің дауыс тануы, 60 секундтық ерікті таймер және жауаптарды сақтау.
- XP, деңгей, белсенді күндер қатары, күндік мақсат, жетістік белгілері және белсенділік диаграммасы.
- Профильде тест жауаптары, сөйлеу жауаптары, жеке ой, сенімділік бағалары және жетістіктер сақталады.
- Қонақ режиміндегі жергілікті прогресс және Google арқылы кіргенде Firestore-мен синхрондау.

XP әр жаңа тапсырма үшін бір рет беріледі, қайталау шектелмейді. Бұл жеке оқу прогресіне арналған жүйе. Сөйлеу бөлмесі грамматика мен айтылымға автоматты баға қоймайды; дауыс тану браузерге байланысты. Зерттеу бөліміне нақты дерек жиналғанда нәтижелер қосылады.

## Firebase қосу

1. Firebase Console → Project settings → Your apps ішінде Web app конфигурациясын алыңыз.
2. `.env.example` файлын `.env.local` деп көшіріп, алты public `NEXT_PUBLIC_FIREBASE_*` мәнін толтырыңыз.
3. Authentication → Sign-in method → Google провайдерін қосыңыз.
4. Authentication → Settings → Authorized domains ішіне `localhost` және кейін Vercel доменін қосыңыз. `127.0.0.1` адресін қолдансаңыз, оны да қосыңыз.
5. Cloud Firestore дерекқорын жасаңыз. Осы жобаның `firestore.rules` ережелерін Rules бөліміне енгізіп, жариялаңыз. Firebase CLI орнатылған болса: `firebase deploy --only firestore:rules --project YOUR_PROJECT_ID`.
6. Dev серверді қайта іске қосыңыз. Vercel-де де осы алты орта айнымалысын қосып, жаңа build жасаңыз.

Config берілмесе сайт қонақ режимінде жұмыс істейді, Google батырмасы өшірулі тұрады. Firebase service account немесе private key қажет емес.

Деректер құрылымы:

- `profiles/{uid}` — аккаунттың негізгі ақпараты;
- `profiles/{uid}/fields/{key}` — жауаптар, жеке ой, мақсат және баптаулар;
- `profiles/{uid}/achievements/{activityId}` — қайталанбайтын жетістіктер.

Ережелер әр оқушыға тек өз профилін ашады. Ұпай жетістік идентификаторларынан есептеледі. Жергілікті көшірме аккаунттың UID мәні бойынша оқшауланады; қонақ ұпайлары есептелмейді және қонақ деректері аккаунтқа көшірілмейді. Қонақтың жауаптары тек ашық сессия жадында болады. Желі қатесі болса, жергілікті дерек сақталып, профильде қайта синхрондау мүмкіндігі көрсетіледі. Басқа құрылғыдағы өзгерістер бет қайта ашылғанда және келесі синхрондауларда біріктіріледі.

## Тексеру

```bash
npm run typecheck
npm test
npm run build
```

Қауіпсіздік ережелері үшін Firebase CLI және Java бар ортада `npm run test:firebase` қолданылады. Бұл тек `demo-speak-without-fear` жергілікті emulator жобасын пайдаланады.

Vercel-ге жариялауды жоба иесі өзі орындайды.

### Email және пароль арқылы кіру

Firebase Console → Authentication → Sign-in method бөлімінде **Email/Password** провайдерін қосыңыз. Google провайдерін де қосулы қалдырыңыз. `/kk/login`, `/kk/register`, `/kk/reset-password` — бөлек беттер; `ru` және `en` нұсқалары бар. Жаңа пароль кемінде 8 таңбадан тұрады. Пароль Firebase Authentication арқылы өңделеді, профильге не localStorage ішіне жазылмайды. Ұпайлар мен жетістіктер тек жүйеге кірген қолданушыға беріледі.

### Жаңартылған жаттығулар

- Қорқыныш қабырғасында 20 жеке жазба сақталады (`wall-01`–`wall-20`); бұрынғы `note` жазбасы да көрінеді. Өшіру бос мәнмен сақталады, сондықтан ескі бұлттық көшірме жазбаны қайта қалпына келтірмейді.
- Сөйлеу бөлмесінде 12 тақырып пен 48 сұрақ бар (`p01`–`p48`).
- Басты бет ойыны әр ашылғанда ауысады және «Келесі тапсырма» арқылы жалғасады. Ұпайлар ойын алаңымен ортақ, қайта берілмейді.
- Жаңа жазбалар мен сөйлеу сұрақтары бұлтқа сақталуы үшін жаңартылған `firestore.rules` ережесін Firebase Console → Firestore Database → Rules бөліміне көшіріп жариялау керек.
